# Blackjack App

🃏 Blackjack Countdown Challenge
A fast-paced, web-based Blackjack game built with HTML, CSS, and Vanilla JavaScript. This version includes a high-stakes countdown timer that forces players to make quick decisions before the clock hits zero!

Link:
[https://rosslergkboquiren.github.io/Blackjack-App/]

🚀 Features
Real-time Countdown: A 60-second digital timer adds pressure to every move.

Casino-Style UI: A sleek, "poker-table green" interface with a digital clock display.

Blackjack Logic: * Aces are counted as 11.

Face cards (J, Q, K) are counted as 10.

Win immediately upon hitting 21.

Responsive Design: Optimized to stay centered on any screen size.

🕹️ How to Play
Start the Game: Click the START GAME button to receive your first two cards and trigger the 60-second timer.

Evaluate Your Hand: Your current sum is displayed below your cards.

Hit or Stand: * Click NEW CARD to draw again if your sum is under 21.

Be careful! If you go over 21, you bust and lose the game.

Beat the Clock: You must reach Blackjack (21) or finish your hand before the timer reaches 00:00. If the time runs out, it's game over!

🛠️ Built With
HTML5 & CSS3: For game structure and casino-themed styling.

JavaScript (ES6): Game state management and setInterval logic.

Gemini AI: Assisted in structuring the countdown logic, CSS layout optimization, and documentation.

📂 Installation & Setup
Clone this repository or download the source code.

Ensure you have three files in the same folder: index.html, style.css, and script.js.

Open index.html in any modern web browser to start playing.
